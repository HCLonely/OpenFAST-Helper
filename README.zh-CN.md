# OpenFAST Helper

[English](README.md) | **简体中文**

为 VS Code 中的 OpenFAST 配置提供语法高亮和离线中英文解释。无需在原配置中添加中文注释，读取及编辑时不会自动改动配置文件。

## 安装

1. 打开 VS Code 的扩展面板。
2. 点击右上角 `…` → **从 VSIX 安装…**。
3. 选择 `openfast-helper-1.2.0.vsix`；若提示重新加载窗口，按提示操作。
4. 打开 `.fst` 或相应模块 `.dat` 文件，右下角语言模式应为 **OpenFAST**。

也可使用命令行：

```powershell
code --install-extension "openfast-helper-1.2.0.vsix"
```

此扩展尚未发布到扩展市场。最低 VS Code 版本为 1.85。

从 [GitHub Releases](https://github.com/HCLonely/OpenFAST-Helper/releases/tag/v1.2.0) 下载 `openfast-helper-1.2.0.vsix`，通过 **从 VSIX 安装…** 安装。开发构建也可在 **Actions → Build VSIX → 成功的运行 → Artifacts** 下载并解压。

## 支持的文本格式

`.fst` 和 `.fstf` 继续直接关联 OpenFAST。启用 `openfast.autoDetect` 后，对纯文本语言模式下的 `.dat`、`.in`、`.inp`、`.ipt`、`.ech`、`.wnd`、`.sum`、`.bmi`、`.lin`、`.out` 和 `.txt`，根据模块标题、参数签名或已识别的输出文件头自动识别。包括 ROSCO `DISCON.IN`、TurbSim 输入、BeamDyn 叶片文件、模块及驱动器输入、回显、汇总、线性化输出，以及具有已知列标题的均匀风文本；另补充 OLAF、ExtPtfm 和 SimpleElastoDyn 输入标题识别。

高亮继续使用本项目的参数/值/注释分离、语义标记和主题配色。补充 ROSCO `!` 后参数名及数组（支持没有尾部说明的记录）、TurbSim 无引号字符串选项、无引号文件名、已知表头、单位行和输出标题。

通用扩展名不做全局关联，保留用户已明确选择的语言。内容依据不足的文件（包括没有标题的纯数字风场/输出文本）可通过语言模式选择器或现有“将当前文件识别为 OpenFAST 配置”命令手动启用。输入文件自动识别保留 2 MB 上限；文本结果文件改用有限文件头识别，不受插件的 2 MB 输入上限限制。二进制 `.outb/.bts`、DLL 和 ROSCO YAML 不在文本高亮自动识别范围内。新增高亮不代表参数词典或校验规则已完整覆盖，TurbSim 主输入文件另有一键运行入口，见下文；不支持直接启动 ROSCO。

依据官方资料补充 ROSCO `.echo/.dbg/.dbg2/.dbg3` 和转子性能表、AeroDisk/AeroAcoustics/结构控制输入标题、TurbSim 用户时序/谱/剖面输入及 `.hh/.u/.v/.w/.cts` 文本、旧版 `.ctp` 输入，以及具有已知列名的 AeroDisk 系数 `.csv` 表。除直接关联的结果扩展名外，自动识别仍需内容依据。对官方支持 key/value 格式的模块，补充参数名在前的编辑器高亮；支持 TurbSim `AnalysisTime-` 等紧贴连字符的参数写法、整行 `#/%` 注释和官方示例表头。新增高亮不扩展运行前严格校验或参数编辑命令对参数名在前记录的支持。

格式重叠时优先保留已有识别和配色。其他语言模式仍受保护：VS Code 通常将 `.hh` 识别为 C++、`.cts` 识别为 TypeScript，需要手动选择 OpenFAST 启用这些文本的高亮。ROSCO 调参 YAML 继续使用 YAML 高亮。TurbSim 二进制 `.wnd/.bts/.bin/.twr` 不作为文本识别。

依据：[ROSCO 控制器文件](https://rosco.readthedocs.io/en/latest/source/rosco.html)、[ROSCO 输入定义](https://rosco.readthedocs.io/en/latest/source/toolbox_input.html)、[OpenFAST 输入格式](https://openfast.readthedocs.io/en/main/source/user/input_file_overview.html)、[AeroDisk](https://openfast.readthedocs.io/en/main/source/user/aerodisk/input_files.html) 及 [TurbSim v2 手册](https://www.nlr.gov/docs/libraries/wind-docs/turbsim_v2-00-pdf.pdf?sfvrsn=5a0a30f8_1) 的附录 A/H 和输出文件章节。

## 使用

未信任工作区中的自动引用检查、文件链接和路径辅助会跳过 UNC/网络文件引用。本地文件引用仍可使用；信任工作区后可启用网络文件引用。

- 参数名、数值、布尔值、路径、分节标题、说明和输出通道分别着色，颜色跟随编辑器主题。
- 鼠标悬停参数名或参数值，查看插件内置参数含义、当前文件实际值及部分适用条件；原始说明与附加注释合并为一个“行尾注释”区块，内容在标签下一行显示。
- 有具体官方说明时提供对应章节链接，例如 [RotSpeed：初始条件](https://openfast.readthedocs.io/en/main/source/user/elastodyn/input.html#initial-conditions)、[PCMode：变桨控制](https://openfast.readthedocs.io/en/main/source/user/servodyn/input.html#pitch-control)。未收录具体链接时明确提示，另提供文档入口。
- 悬停表格列名或数据单元格，查看对应字段说明。悬停 HydroDyn 附加矩阵的数值，查看行列自由度及单位。
- 输出列表内的通道逐个提供说明，支持引号包裹的多个逗号分隔通道。
- 按 `Ctrl+Shift+P`，执行 **OpenFAST: 查询参数说明**，可按英文参数名或中文关键词搜索离线词典。
- 编辑固定选项参数值时自动显示下拉书写建议，显示可选值和中文含义，例如 `WaveMod` 的 `0 — 静水`、`1 — 规则波`、`2 — JONSWAP / PM 不规则波`。点击目标建议即可替换值；自动弹出受 VS Code 的“建议：在触发字符上显示”设置控制。
- 原有可选值悬停说明、行旁灯泡的“选择固定选项”入口及 **OpenFAST: 选择当前参数的固定选项** 命令继续保留。选择只替换标量值，保留缩进和注释；插件不绑定固定选项快捷键。
- 按 `Ctrl` 点击（macOS 为 `Cmd` 点击）输入文件路径，打开存在的引用文件；`PotFile` 跳到同根名 `.hst`。
- 使用“大纲”面板按章节定位参数。
- 未自动识别时，执行 **OpenFAST: 将当前文件识别为 OpenFAST 配置**，或点击右下角语言模式选择 OpenFAST。

`.fst/.fstf` 自动关联；其他支持的文本格式根据文件头和多个参数特征识别，保留用户已选择的其他编程语言。插件不会将所有 `.dat` 文件全局关联为 OpenFAST。

## 排版、一致性与可重复验证（0.15.0）

1. **沿用表格排版**：行尾接受 ID、引用或枚举后，优先采用附近 20 行内、最多 8 个同字段样例的逗号、Tab 或空格分隔方式；相邻行列起点一致时尽量延续对齐，最多补 80 个空格。已有单元格、分隔符、注释及物理数值不重排；找不到依据时沿用原有 Tab 回退。新插入的表格行模板也沿用附近分隔符，字段占位仍需填写。
2. **统一字段上下文**：编辑快照为显式连续逗号保留空单元格，并让高亮、悬浮、引用建议、字段诊断与签名使用相同字段映射。带引号的逗号仍属于值，原 UTF-16 位置保留。未知变长计数只映射已知前缀；普通空白不推断中间漏列。严格求解器解析和物理规则保持独立。
3. **原生撤销**：补全的值、自动引号与行尾分隔符由同一次原生补全编辑提交，不增加接受后的改写命令。真实宿主验证选区、多光标、路径和中文变更保护恢复后的补全，一次撤销恢复补全前文本。
4. **手动查询建议原因**：执行 **OpenFAST: 显示输入建议及空结果原因**，展开原生建议；本插件所有相关提供器结束后若均无候选，再说明缺少定义、计数不明确、节点范围未知或设置停用等原因。也可执行 **OpenFAST: 查看当前位置的建议原因** 直接查询，并打开对应设置、路径审阅或数组模板入口。不会加入假的补全项；取消、失败、过期或光标变化时保持安静。VS Code 的 Invoke 同时用于手动与自动建议，因此仅这两个明确命令启用说明，普通自动输入不弹消息。这里判断的是本插件候选，其他扩展或编辑器词语建议独立运行。
5. **数组逐元素反馈**：对上一版核验的 ElastoDyn/AeroDyn 四类节点数组，检查有效明确计数下的项数、整数类型、节点下限和本文件唯一明确的上限，精确标出对应元素。活动行延迟反馈；零计数允许保留被忽略的占位值，未知上限不报越界，重复节点不作为禁用规则。沿用 `openfast.enableTableFieldDiagnostics` 控制，仅编辑反馈，不自动修复或更改运行前规则。
6. **主题预览与重叠控制**：只读预览新增故意错误的枚举、未解析引用、带符号的 Fortran 指数和 AeroDyn 数组样例。字段分组点线遇定义/引用角色边框或当前单元格边框时让位；三种内置主题验收保持语义类型一致。预览供实际主题比较使用，不是完整求解器输入。
7. **固定性能回归**：提供可重复的补全性能基准和报告，运行方法及比较限制见 [开发说明](Development.zh-CN.md#性能基准)。

## 高亮与输入辅助（0.14.0）

1. **可恢复显示预设**：执行 **OpenFAST: 切换高亮与提示预设**，选择阅读、表格或结构视图；只调整显示项。首次应用时持久保存原有覆盖，切换多个预设后仍可恢复，包括删除原本不存在的覆盖。优先当前文件夹，其次工作区、用户范围；各文件夹独立保存。
2. **字段错误解释**：表格值悬浮显示实际值、预期类型、单位、明确选项和当前错误；已确认引用附定义行链接。灯泡提供参数名或枚举拼写的单项修复，用户选中后才执行；既有数值/字符修复继续保留。
3. **缺失路径替代文件**：执行 **OpenFAST: 查找缺失路径的替代文件**，或选择缺失文件诊断的灯泡入口，查看原值 → 替代值后再接受。搜索当前目录及下两层、当前工况已知引用，最多访问 24 个目录、处理 600 项和 300 个引用；最多核验 24 个候选、每个文件头上限 128 KiB。模块不符降序，未知头明确标注；保留引号、注释、路径分隔风格及 PotFile/FilenameRoot 根名称。不遍历链接或隐藏目录，文档变化时取消替换，不自动保存。
4. **下一待填字段**：执行 **OpenFAST: 下一待填表格字段**，定位字段名占位或缺失的行尾单元格并打开建议；完成表格不产生目标。缺失尾部须从首个空字段依次填写，未知变长计数只处理已确认前缀；不填物理数值。此命令限 200 万字符以内的文档。
5. **可选字段分组**：开启 `openfast.highlightTableFieldGroups`，以主题点线区分可见表格中的定义、引用、几何和系数字段；默认关闭，最多装饰 2000 个单元格，不替换语义颜色。超大文档保留原有局部高亮。
6. **核验后的数组辅助**：本轮扩展 ElastoDyn `BldGagNd/TwrGagNd`、AeroDyn `BlOutNd/TwOutNd` 的计数位置提示、模板和节点范围候选，保留原有 `LinTimes`。依据 [ElastoDyn v4.0.5](https://openfast.readthedocs.io/en/v4.0.5/source/user/elastodyn/input.html#outputs) 与 [AeroDyn v4.0.5](https://openfast.readthedocs.io/en/v4.0.5/source/user/aerodyn/input.html#outputs)，规则版本限 4.0；未知版本附核验提示，明确选择其他版本时不启用本轮数组规则。节点范围必须在本文件唯一明确，`BlOutNd` 不跨叶片文件猜范围，仍提供填写占位。零/重复/非法计数不生成值，模板遇多余已有元素停止。候选最多 500 项，已选节点排后；数值字符串与逐元素补全的分号/逗号保持原样。
7. **候选依据**：路径、表格引用、JOutLst 和输出候选说明工况引用、模块核验、定义来源或已选后排的依据；仍按已有规则和自然数字排序。
8. **实测性能报告**：执行 **OpenFAST: 查看编辑性能诊断**，打开只读报告，显示本次会话实际补全/高亮/快照构建耗时、缓存命中与当前文档规模。最多保留 24 类操作、每类最近 128 个样本；平均/最大统计累计调用，p95 取近期样本。包含异步等待与取消调用，不代表响应延迟基准；再次执行刷新。
9. **疑似错列提示**：固定列表格恰少一项且观察到类型/枚举冲突时，检查插入空位是否能解释错位，列出可能缺失字段。纯数值无法区分、未知变长计数或无依据时不推断；仅信息提示，不移动数据，运行前严格检查保持原规则。

## 阅读定位与候选选择（0.13.0）

1. **自然排序**：表格 ID、JOutLst、路径文件名和编号输出通道按数字片段排序，例如 `2` 在 `10` 前；已有项降序、路径用途和工况相关优先级继续保留。
2. **列表摘要**：引用候选直接显示定义坐标/字段摘要，最多 80 字符；完整内容保留在详情。输出候选展示单位、物理量分类和已收录含义，搜索仍仅使用英文通道名称。
3. **当前值提示**：开启 `openfast.showCurrentValueHint` 后，当前标量行显示固定选项含义及内置词典明确提供的单位；compact 精简含义和单位标签，detailed 保留悬浮说明。未知单位不推测，默认仍关闭。
4. **高亮预览**：执行 **OpenFAST: 预览高亮与提示**，选择 OpenFAST、HydroDyn、MoorDyn 或 ElastoDyn 的只读示例，在旁边的原生设置页调整显示选项。示例不是完整求解器模板，不执行仿真或检查示例路径存在性。预览采用当前窗口适用的设置；文件夹专属覆盖应在实际文件中核对。
5. **表格十字定位**：当前单元格使用主题焦点边框，与所在行及对应列区分；开启表格高亮和提示时，状态栏显示当前物理列、字段及单位，横向滚动仍能定位。
6. **上游控制来源**：悬停子文件标量参数/值时，展示当前工况图中已确认的上游引用角色、控制字段、数值、来源文件和跳转链接。当前选中的主工况优先；无明确主工况且存在多个来源、重复定义、路径已改变或图尚未建立时省略提示。仅说明引用启用条件，不推断参数的全部物理生效条件，不改变原有淡化规则。
7. **分类浏览输出**：在普通 OutList 内的空白行执行 **OpenFAST: 按物理量浏览输出通道**，选择运动与姿态、力与载荷、风与波浪、发电机与控制或其他已收录通道，再勾选实际插入项。仅使用当前模块已有/动态/补充词典候选；排除已添加项，保留引号与缩进。节点列表仍使用原有专属补全。
8. **高亮稳定性**：文档版本及装饰范围相同时不重复提交装饰；未完成数值、引号和语义令牌增量更新继续由回归测试保护。
9. **路径候选稳定性**：异步核验仅更新选中候选的说明，不改同次列表排序、插入内容或替换范围；重复/并发解析不叠加模块说明，下次请求可使用已核验缓存排序。
10. **诊断去重**：同一单元格已有类型/枚举反馈时，省略派生引用错误；额外单元格反馈替代相同位置的重复列数提示。不同单元格和不同规则的问题保留，运行前严格检查输出不变。

## 字段一致性与上下文辅助（0.12.0）

1. **NodeLocs 变长字段**：按明确的 NOutLoc 展开位置、单位、签名与数值反馈；零计数不制造列表项，未知计数只映射确定的前缀。
2. **共享表格规则**：编辑反馈和运行前检查共用字段类型、枚举与特殊值判定；编辑时暂缓当前行提示，运行前保留严格检查。
3. **JOutLst 建议**：逐元素补全现有 JointID，显示定义摘要和当前项/总项，已选项排后；替换保留其他元素、分隔符和注释。
4. **表格特殊值**：FillDens 提供 DEFAULT；三个系数模型的横向 Cp/CpMG 字段提供 MCF，其他数值仍可直接填写。字段范围依据 [HydroDyn 官方输入说明](https://openfast.readthedocs.io/en/v4.0.5/source/user/hydrodyn/input_files.html#hydrodynamic-coefficients)。
5. **类型化行模板**：已识别固定列表格提供未用 ID、已有定义引用和枚举选项；物理数值保留字段名占位，变长列表仍需明确计数后填写。
6. **导航**：从已确认的同文档定义/引用跳转、预览定义和查找引用；重复定义返回多个位置，不猜跨文件关系。
7. **局部中文保护**：800 ms 静默保护限中文变更所在行，其他行仍可补全；行数变化清除旧范围。仍以已提交文本变更为依据。
8. **大文件上下文**：超过 2 MB 时缓存远距表头/输出列表锚点，为可见区域高亮和表格引用补全提供上下文，支持同文档分栏。索引上限 12,000,000 字符、250,000 行、4,096 锚点，每个窗口最多 800 行；定义采样每表 256 行、合计 2,048 行。超过上限保留基础语法回退；局部索引不提供未用 ID，避免误判全局占用。
9. **自定义输入约束**：词典参数可选 valueType（number/integer/boolean/string）、options（最多 50 项）、specialValues（最多 20 项），用于值建议、悬浮说明和编辑诊断。值限 80 字符的单个 ASCII 词元，不支持空白、引号或片段表达式；不覆盖内置规则。按资源/模块/版本隔离。
10. **主题兼容**：所有自定义语义类型声明标准父类型及基础语法作用域；支持浅色、深色和高对比度主题的继承配置。

词典示例：`{"module":"SeaState","kind":"parameter","name":"CustomWave","description":"自定义波浪模式","valueType":"integer","options":["1","2"],"specialValues":["DEFAULT"]}`。

## 安全编辑与候选反馈（0.11.0）

1. **定义与引用区分**：开启 `openfast.highlightSymbolRoles` 后，已确认的结构定义、有效引用和未解析引用使用独立语义作用域；可见区域同时提供边框、点线或波浪线标识。默认关闭，沿用主题颜色，200 万字符以上不建立全文件关联装饰。
2. **安全重命名**：使用 VS Code 原生“重命名符号”，支持已识别的 MoorDyn 点/线 ID、线型名称，以及 HydroDyn/SubDyn 已确认的结构定义列。更新同一文档中已解析的引用，多处编辑携带原生审阅确认信息；重名、重复定义、非规范 ID 或不确定关系会停止。HydroDyn 成员系数/输出表与 `JOutLst` 也参与关联；不做跨文件重命名，也不按文本匹配改写注释或动态输出通道名称。
3. **表格类型反馈**：检查已知整数/枚举/数值字段，保留明确支持的 `DEFAULT/MCF`。正在编辑行的类型和引用检查延后到离开该行，未知字段不猜测物理范围；可通过 `openfast.enableTableFieldDiagnostics` 关闭新增反馈。
4. **多余单元格定位**：逐个标出超出表头的单元格，并提示检查错列；`FillNumM` 未知时不推测后续字段位置。只提示，不自动移动数据。
5. **成员列表重复反馈**：对 HydroDyn 当前填充组 `FillMList` 内重复成员给出信息提示，候选中已选择成员排后但仍可选。未将该提示定义为求解器错误，也不对其他允许重复的引用列套用此规则。
6. **路径内容核验**：已读取的候选若检测到模块与 `EDFile/HydroFile` 等用途不符，会显示需要/实际模块并降低排序；读取失败、未知文件头和超过 128 KiB 的文件分别说明。小目录最多预读 24 个候选，大目录选中后延迟核验；未核验候选不视为兼容性已通过。
7. **长表格签名精简**：超过 9 列默认展示首尾及当前列前后各 2 列，最多 7 个字段，显示当前物理列和变长列表总数。关闭 `openfast.compactTableSignatures` 可显示全部字段，各字段保留类型/单位说明。
8. **数值分段高亮**：开启 `openfast.highlightNumericParts` 后，完整数值的前导正负号、尾数和 `E/D` 指数分段着色；未完成指数保留基础高亮，不改变数字或精度。主题可以为 `openfastNumericSign/openfastNumericExponent` 自定义颜色。
9. **接受补全后的光标**：路径保留一对引号，目录建议将光标留在闭引号前以继续浏览；未完成表格行末接受 ID/枚举后补一个 Tab 继续下一列。已有空格、Tab、逗号和后续单元格不被吞掉；Tab 的实际显示遵循编辑器缩进设置。
10. **输入稳定性**：中文/日文/韩文文本变更后使用 800 ms 静默窗口，暂停替换型纠错并延后编辑诊断；延迟数值/字符诊断和候选说明检查文档版本、关闭及取消状态。VS Code 没有公开输入法组合状态事件，因此这属于文本变更后的保护，不代表能检测所有输入法的未提交组合过程。

以上功能默认启用，不绑定自定义快捷键。悬停说明、固定选项下拉建议及原图标定制继续保留。未保存的编辑内容会参与检查和比较；插件不会自动保存或修改工况输入。

版本 auto 仅识别文件头前 15 行中明确的 OpenFAST 版本号，子文件可继承当前主文件版本；无明确版本时依据本行选项说明，不推断版本。版本规则覆盖官方已核验的 CompAero/CompElast 选项变化及部分 5.0 新增/移除字段，尚未实现各版本完整输入格式校验。旧版文档使用可用的官方版本入口；不能确认旧版锚点时不会拼接链接。

通道建议覆盖内置 119 条记录，未知通道可继续输入且不直接判错。表格辅助仅处理由内置 161 个字段识别的表格，不覆盖任意数值文件和全部模块专有格式。关系图默认最多读取 300 个文本配置，每个文件限制 2 MB；二进制风场、DLL 和 WAMIT 系数文件只检查引用存在，不执行或比较其数据内容。工况比较遍历启用的文本引用；未识别表格、单位行变更、注释和输出排列顺序不计入差异，无法读取及达到文件上限时报告会说明。

### 输出通道建议的使用

在模块文件的 OutList 或 OUTPUT CHANNELS / OUTPUTS 区域，END 前新起一行，输入双引号，或输入通道前缀（例如 `"Rot`、`"Wave`、`"Gen`）。点击候选即可插入；引号、小写和大写字母均可触发。

已有通道标注“已添加”并排在后面，当前正在编辑的通道不会被自身标记。0.2.0 曾把已有项全部过滤，导致某些真实工况中没有任何候选，0.2.1 已修复。

命令面板提供 **OpenFAST: 输出通道建议设置**，可直接定位该开关；也可在设置搜索框输入 `@id:openfast.enableOutputSuggestions`。插件为 OpenFAST 语言默认开启字符串内快速建议，不修改用户全局设置；用户显式禁用编辑器建议时仍尊重该设置。

## 结果文件高亮与 TurbSim 诊断

TurbSim 文件悬停中的文档入口为 [TurbSim v2.00 用户手册（PDF）](https://www.nlr.gov/docs/libraries/wind-docs/turbsim_v2-00-pdf.pdf?sfvrsn=5a0a30f8_1)；ROSCO 文件使用 [ROSCO 官方文档首页](https://rosco.readthedocs.io/en/latest/)。

.out/.dbg/.dbg2/.dbg3/.echo 默认使用 **OpenFAST Results** 语言模式，显示表头、单位、数字及科学计数法。其他支持的文本结果（例如 .sum/.lin/.hh/.u/.v/.w）根据文件头识别；保留用户明确选择的其他语言。无标题结果可在语言选择器中手动选择 **OpenFAST Results**。二进制 .outb/.bts 无法作为文本高亮，.outb 请使用现有结果预览入口。

结果文件与输入文件采用独立的语言模式，不将数据列当作配置参数校验。自动检测最多读取前 150 行、64,000 字符；大结果的语义高亮只处理可见区域，单次最多 800 行、1,000,000 字符和 50,000 个标记，不扫描整份数据表。结果模式默认关闭 VS Code 的大文件高亮优化限制；用户设置仍可覆盖。超过 VS Code 扩展宿主同步上限时使用语法高亮，实际可打开的大小仍受编辑器和内存限制。升级前已经打开的结果文件需关闭并重新打开。

内置 TurbSim 的 69 条参数说明与 ROSCO 的 199 条参数说明，提供中英文离线悬停、查询及补全说明，无需给输入文件添加注释。覆盖 TurbSim 主输入及常用用户输入字段，以及 ROSCO DISCON 的滤波、变桨、转矩、风速估计、浮式反馈和启停等参数；版本专属选项以对应版本文档为准。

TurbSim 的 `WindProfileType`（如 `PL`）和 `CTEventFile`（`LES`、`DNS`、`RANDOM`）属于选项，不生成文件不存在提示或路径补全。`UserFile` 只在 USRINP/TIMESR 模型下检查，`ProfileFile` 只在 USR 剖面或 USRVKM 模型下检查。`CTEventPath` 为事件数据库目录，当前不展开检查目录中的事件文件。参数说明不代替 TurbSim 的完整输入校验。

输入格式检查使用内置字段类型，覆盖 TurbSim 的 69 个字段和 ROSCO 的 195 个当前字段，不依赖行尾注释推断数值类型。支持 TurbSim 的 `UsableTime="ALL"`、`RandSeed2="RANLUX"/"RNSNLW"`、双值相干参数及 `AnalysisTime-` 紧贴分隔符的写法；检查数值、整数、固定值数量、网格点数至少为 2 和时间步长等正值。ROSCO 的 `DT_Out=0` 合法；关闭 OL_Mode、Ext_Mode 或 WE_Mode 时，不检查对应的可选引用文件。旧版字段和其他版本专属规则尚未完整覆盖，最终以相应程序的校验为准。

## 一键运行 TurbSim

1. 在 VS Code 中打开受信任的本地工作区，打开 TurbSim 主输入文件（支持 .inp/.in/.dat/.txt）。识别要求文件前 150 行、64,000 字符内包含主网格参数 NumGrid_Z、NumGrid_Y、TimeStep 和 AnalysisTime；用户时序、谱、剖面等辅助文件及输出文件不能直接启动。
2. 点击状态栏 **TurbSim 路径**，或执行 **TurbSim: 配置可执行文件路径**，选择 TurbSim 程序（例如 TurbSim_x64.exe）。设置项为 `openfast.turbSimExecutablePath`，与 OpenFAST 路径独立保存；未配置时首次运行会打开选择器，设置不可写时使用插件存储。
3. 点击编辑器右上角 ▶，或在资源管理器右键输入文件选择 **TurbSim: 运行主输入文件**。通用扩展名的右键菜单也可能显示此命令，执行时会检查内容。同一输入文件正在运行时不会重复启动。TurbSim 输入（含辅助输入）和 ROSCO 输入不显示 OpenFAST 的检查整个工况、对比工况及运行监控工具栏按钮；OpenFAST 主文件及其模块输入保留这些入口。

启动前自动保存当前主输入文件；保存失败会停止启动。工作目录为输入文件所在目录，程序通过独立参数接收输入文件完整路径，原始输出显示在 VS Code 任务终端。可通过“终端 → 终止任务”停止，非零退出会提示查看终端。此入口不进入 OpenFAST 运行队列或计算进度监控，不套用 OpenFAST 工况预检查；辅助文件的修改需自行保存，输入正确性由 TurbSim 校验。自动识别最多处理 2 MB 文本文件；打开或编辑文件不会自动运行程序。

## 运行工作流（0.5.0）

- **运行前统一检查**：单次及批量运行共用文件关系图，检查相关未保存修改、启用的引用文件、已知参数规则和跨文件约束。保存后重新发现引用；失败保存、错误和不完整读取会阻止本次运行。相关文件的保存和检查对话框按顺序处理。
- **运行日志诊断**：终端显示程序原始 stdout/stderr；运行结束后，将识别的错误及中英文解释放入“问题”面板。只有文件名或参数能唯一确定时才定位到对应文件或参数；否则定位主文件开头。非零退出但未识别日志时提供通用错误。重跑会清除该工况旧的运行诊断。
- **批量运行队列**：执行 **OpenFAST: 批量运行 FST**，在选择框中多选 `.fst/.fstf`。资源管理器中的 **OpenFAST 运行队列** 显示等待、运行中、成功、失败及已取消状态；支持取消单项、取消全部、重跑失败或取消的工况、打开工况目录。
- **并发数**：`openfast.runConcurrency` 默认 `1`，可设置为 `1–16`；下次提交工况时生效。取消中的进程完全结束前占用并发槽位，避免提前重跑。队列和状态在当前窗口内保留，重载窗口后不恢复。

日志分析使用最后 1,000,000 个字符，最多生成 50 条运行诊断；原始输出仍在任务终端中，保留量受终端滚动缓冲设置影响。解析器提供常见错误的检查方向，不保证覆盖全部 OpenFAST/控制 DLL 日志格式。工况目录入口指向主文件所在目录。运行前检查使用已有的离线规则，不能替代 OpenFAST 自身校验。

## 计算进度监控（0.6.1）

最左侧与“资源管理器 / 搜索 / 扩展”并列的竖栏默认提供 **OpenFAST 计算进度** 波形图标。点击后打开任务列表；启动时不主动打开监控页，也不扫描进程。仅当侧边栏监控或编辑区监控至少一个可见时，每 5 秒扫描一次；两者都关闭或切到后台后停止扫描和界面定时刷新，再次显示时立即刷新。停止监控不会停止 OpenFAST 计算。点击 **在编辑区打开** 可展开完整列表；状态栏和运行队列标题栏也可打开监控。升级后需执行一次 **开发人员: 重新加载窗口**；若手动隐藏过图标，可在最左竖栏右键重新勾选。

列表显示工况、状态、PID、仿真时间 / TMax、百分比、已用时间、监控估算剩余、OpenFAST 剩余及进度来源。支持按工况名、路径、PID 搜索，并筛选运行 / 等待、本次会话全部、已结束或失败任务。侧边栏使用紧凑列表，选择工况可查看路径、工作目录、命令行、报告时间、原生 ETA 原文，也可打开工况目录或关联日志。

进度采集参考本地 `OpenFAST_Monitor` 的 Rust 实现：

- 在受信任的 Windows 本地工作区，每 5 秒发现本机 OpenFAST 进程；界面每秒刷新。Windows x64 安装包内置只读原生进程探针，读取命令行、工作目录、创建时间，支持 WOW64 进程。相对 `.fst/.fstf` 根据求解器实际工作目录解析，不要求工况位于当前工作区。探针不能运行时退回 CIM，此时相对路径仅使用工作区唯一匹配。
- 插件任务与外部进程按 PID 去重；外部任务使用 PID 和创建时间区分。进程参数权限不足时仍显示任务，标注读取问题；不会猜测工作目录或终止求解器。
- 读取当前启动之后更新的同名 `.log` / `.stdout.log` / `.stdout`，也支持工况目录日志、`runs/<尝试>/stdout.log`、`stderr.log` 和 PID 匹配的 `run_status.json` 所指日志。目录日志只有在该目录没有多个活动工况时自动使用；同工况多进程不自动分配日志，可显式关联。旧日志和输出按启动时间排除，每个文件最多读取末尾 128 KiB。
- 从同名文本 `.out` 的最后完整数据行获取仿真时间，使用 FST 中的 TMax 计算百分比；尾部正在写入的不完整行忽略。日志和文本输出都可提供进度，选择更新的仿真时间。只有 `.outb` 且没有日志时不推测实时进度。
- **监控估算剩余**依据已用时间和当前仿真进度计算；**OpenFAST 剩余**独立读取最近一次完整的 `Estimated final completion at ... (in ... days)`，不会用监控估算值代替。新的不完整 ETA 不会覆盖上一条完整报告；求解器天数经过舍入，换算时长也是近似值。仅文本输出时可显示监控估算，原生 ETA 显示 `—`。
- OpenFAST 原生剩余时间保持最近一次报告，不自行倒计时；任务结束后原生 ETA 显示 `—`。预计完成时刻保持原文中的本地时钟值，不擅自补日期。超过 30 秒没有新进度时在详情中提示报告较旧，不据此判断进程停止。
- 进程仍存在时保持运行状态，即使日志含致命错误也仅作提示；退出后根据本次运行日志或 PID 匹配状态文件的正常/失败证据分类，没有证据则标为退出状态未知。插件自己的任务继续采用运行队列状态。查询失败保留上次进程状态。

保留最多 100 条已结束记录，支持清除；重载窗口后重新发现仍运行的进程。外部发现限 Windows，原生探针限 x64（其他 Windows 架构退回 CIM）；其他系统中插件启动的任务仍接收控制台进度。不会读取远程窗口或未信任工作区的本机进程。外部任务既没有日志也没有文本输出时只能显示进程状态；无法事后读取其他终端已输出的控制台内容。

安装包内置 Windows x64 原生探针，用户无需安装 Rust。探针重建方法见 [开发说明](Development.zh-CN.md#原生探针)。

## 参数扫描与工况生成（0.6.0）

打开基准 `.fst/.fstf`，点击编辑器标题栏或 OpenFAST 配置树标题栏的参数扫描图标，或执行 **OpenFAST: 参数扫描与工况生成**：

1. 多选需要扫描的数值标量（最多 8 个），逐项输入逗号或空格分隔的数值，例如 `8, 10, 12`；支持 D/E 指数，不解析区间表达式。
2. 查看组合表、每个工况的配置文件数、预计写入量和共享资源清单。修改取值后先点 **更新组合预览**，再点 **生成到新目录**。
3. 选择父文件夹，插件创建带时间戳的新扫描目录；生成后可点 **运行已生成工况** 提交到既有运行队列。

最多生成 200 个笛卡尔积组合。扫描候选排除已知未启用参数、文件引用、数组、固定选项及常见计数字段；改变文件引用或启用状态、违反已知参数规则或跨文件约束的组合会被拒绝。预览使用打开时的输入快照，包括未保存修改；再次打开扫描可读取新的快照。

每个工况有独立的文本配置副本，包括已识别的 ROSCO 控制器输入；同一个被多处引用的文本文件在每个工况中只复制一次。配置之间的引用重写为相对路径，风场、DLL、WAMIT 系数等外部资源通过绝对路径共享。原始研究输入不会被改写；移到其他计算机前需要另外复制共享资源。仅处理插件能够识别的文件引用，第三方控制器或自定义模块的未知路径需要人工核对。

根目录的 `sweep-manifest.json` 记录基准路径、参数取值、共享资源和生成主文件。已有目录不会覆盖；写入失败时保留 `.incomplete.json` 标记及已写入的文件，检查后可自行处理。只有完整生成成功后才提供运行入口。

## 输出结果快速预览（0.6.0）

初次读取文件信息时显示可取消的进度。文本文件头每行最多 1,000,000 字节，累计扫描最多 4,000,000 字节；超过限制的文件头会被拒绝。数据行保留 32,000,000 字节上限，支持 UTF-8 文件头以及 LF、CRLF、CR 换行。

执行 **OpenFAST: 预览输出结果**，选择最多 4 个本地 `.out/.outb`；也可以在资源管理器右键选择该命令。支持标准 OpenFAST 文本结果，以及二进制格式 ID 1、2、3、4（含压缩时间、压缩通道、双精度未压缩数据和长通道名）。二进制定义对照 [OpenFAST 官方工具箱读取代码](https://github.com/OpenFAST/openfast_toolbox/blob/main/openfast_toolbox/io/fast_output_file.py) 实现。

- 搜索并勾选最多 4 个通道，填写起止时间（秒），点击 **更新曲线与统计**。每个通道分别绘图，跨文件叠加仅使用名称、单位均一致且无歧义的通道。单文件内的重复通道名按实际列号标记。
- 显示区间内的有效/非有限样本数、均值、总体标准差、最小值和最大值；NaN/Inf 从统计中排除并单独计数，时间必须有限且严格递增。
- 曲线按时间分桶保留首尾点和极值，每条曲线最多 2,000 点；统计使用区间内的全部有效样本。可悬停或用左右方向键查看保留点，原始数据文件保持不变。
- **导出统计 CSV** 保存源文件路径、通道名、列号、单位、请求时间区间及完整样本统计。它是统计表，不是降采样曲线或原始时序导出。

采用流式/分块读取，不将整个结果载入编辑器；大文件仍需要扫描时间。关闭预览会取消读取。读取中发现文件大小或修改时间变化时要求重新打开，避免混用计算尚未完成的结果。预览只读，不执行模型；界面使用 VS Code 主题及离线脚本。

结果预览可通过 OpenFAST 配置树标题栏的折线图图标选择输出文件，也可点击 `.out/.outb` 编辑器标题栏的预览图标，无需使用命令面板。

## 配置文件图标

执行 **OpenFAST: 设置 OpenFAST / TurbSim / ROSCO 文件图标（保留原主题）**，在当前 **vscode-icons** 主题中应用浅色/深色图标：

- OpenFAST：.fst/.fstf/.dat/.ipt/.bmi 输入和 .sum/.out/.outb/.lin/.ech 汇总、结果及回显使用风机与波浪图标。
- TurbSim：.inp/.ctp 输入及 .bts/.wnd/.hh/.u/.v/.w/.cts/.twr 风场文件使用风场图标。
- ROSCO：DISCON.IN 及 .echo/.dbg/.dbg2/.dbg3 使用控制器图标。

已经启用 OpenFAST 图标的工作区，升级并重新加载窗口后会自动补充缺失关联；首次设置仍需执行图标命令。图标按扩展名或完整文件名关联，不读取文件内容；例如其他软件的 .inp 也会使用风场图标。通用 .in/.txt/.csv/.yaml/.yml/.bin 和动态库保留原主题的图标，DISCON.IN 按完整文件名单独关联。任意名称的 ROSCO 调参 YAML、性能表 TXT 或 TurbSim BIN 不按内容定制文件图标。图标不表示文件可以直接运行，也不表示二进制文件能文本高亮。

插件写入六个 SVG，合并目标关联并刷新 vscode-icons；保留其他关联，不修改当前图标主题。优先保存到工作区，无工作区时保存到用户设置。其他图标主题暂不支持局部定制，会保留原主题并提示。实现遵循 [vscode-icons 自定义图标](https://github.com/vscode-icons/vscode-icons/wiki/Custom) 和 [关联配置](https://github.com/vscode-icons/vscode-icons/wiki/FineTuning)。

## 支持范围

内置 750 条参数记录（含模块特定同名字段）、161 个表格字段及 119 个输出通道记录，并动态解释任意编号的 MoorDyn 两端张力通道。重点覆盖 OpenFAST 主文件、ElastoDyn、InflowWind、ServoDyn、SeaState、HydroDyn、MoorDyn；TurbSim 与 ROSCO 提供模块专属参数说明，AeroDyn、结构属性提供常用说明。可识别 BeamDyn、SubDyn 文件头，但尚未完整收录这些模块的全部参数。

解释结合当前文档值，不会把原示例工况的风速、时长、转速或启用状态当作其他文件的事实。适用条件提示覆盖常见风场、控制器、线性化及部分海况/水动力开关，不是完整的版本校验器。未知字段会保留本行英文说明并标明中文库尚未收录。已有 `! 中文说明：` 行尾注释与原始说明一起归入“行尾注释”区块，完整保留所有注释内容，不覆盖内置词典，也不需要向原始配置文件写入说明。

内置官方链接索引包含 408 个模块参数条目，依据 [OpenFAST 官方文档](https://openfast.readthedocs.io/en/main/source/this_doc.html) 的 main 分支及其引用的 MoorDyn 官方输入说明，核验日期为 2026-10-09。索引只记录含描述的段落、表格或定义列表所在的真实章节，不根据参数名拼接虚构锚点。它并非全站（含 PDF 手册）的完整索引；没有链接只表示当前索引未收录，不代表官方没有说明。中文说明和链接索引均随 VSIX 打包，悬停和查询无需联网；点击外部链接时才由浏览器访问文档。

参数选项及输入格式随 OpenFAST 版本变化，原文件说明和所用版本的官方文档优先。说明与检查采用离线词典；只有显式执行运行命令时才调用相应的 OpenFAST 或 TurbSim 程序。运行时模型可能加载其配置的控制 DLL。

固定选项优先取当前行的 `{1=...; 2=...}`、`[1=..., 2=...]` 或括号选项说明，兼容布尔开关及 `[10, 11, or 12]` 分组选项；缺少说明时使用常见模块参数的内置选项，并标注需要核对版本。没有封闭选项列表的连续量、矩阵、数组和文件路径不提供此菜单；例如 `NumCrctn` 注释中的 `0=无修正` 只是一个特殊值，不会被当作完整选项。当前工况七个配置文件中有 102 个标量字段可选择。当前不支持 ROSCO 值在 `! 参数名` 前的选项菜单，也不把 `WaveMod=1P#` 的可变相位表达式当成固定值；这些内容继续手动输入。

## 显示语言

默认 `openfast.language = "auto"`，跟随 VS Code 界面语言：中文界面使用简体中文，其他界面使用英文。通过设置选择 `zh-CN` / `en`，或执行 **OpenFAST: 选择显示语言 / Select display language**，可即时更改悬浮说明、参数查询、建议、诊断及运行提示语言。命令菜单、设置标题和视图名称由 VS Code 根据界面语言加载 `package.nls`，手动覆盖扩展语言不会更改 VS Code 界面。

750 条参数、161 个表格字段及 119 个通道均内置中英文说明。文件内已有的注释保留原文：中文模式显示“内置说明”和“行尾注释”，英文模式显示“Built-in description”和“Line comments”。英文、中文及混合注释均完整显示，包括“中文说明：”之前的文本；即使与内置说明重复也不会省略。`openfast.showOriginalDescription` 控制整个行尾注释区块。

扩展生成的查询标签、固定选项、表格说明、诊断、运行提示和新建差异报告均支持中英双语。配置文件自身的注释、分节名称、路径、参数/通道/模块名称、官方章节原名以及 OpenFAST/操作系统返回的内容保留原文。已生成或导出的报告保持生成时的语言；切换语言后重新比较可生成对应语言报告。
